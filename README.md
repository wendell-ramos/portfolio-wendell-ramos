## Sobre o projeto

Este repositorio contem meu portfolio pessoal, desenvolvido como uma experiencia interativa inspirada em interfaces classicas de desktop.

Em vez de uma pagina convencional, o visitante pode explorar atalhos, abrir janelas, utilizar o menu Iniciar e navegar pelas diferentes areas do meu perfil profissional.

O projeto apresenta minha trajetoria como estudante de **Sistemas de Informacao**, experiencias profissionais, habilidades tecnicas, projetos desenvolvidos e eventos dos quais participei.

## Funcionalidades

- Interface inspirada em um desktop retro
- Janelas arrastaveis, minimizaveis e maximizaveis
- Menu Iniciar e barra de tarefas funcionais
- Apresentacao profissional e experiencia recente
- Projetos com capas personalizadas, selos de status e links externos
- Linha do tempo de eventos em ordem cronologica
- Fotos de eventos com visualizacao ampliada
- Visualizacao e download do curriculo em PDF
- Contatos por e-mail, WhatsApp, LinkedIn e GitHub
- Idade atualizada automaticamente
- Layout responsivo para desktop, notebook, tablet e celular

## Projetos apresentados

### Edvaldo Films

Portfolio audiovisual desenvolvido para um filmmaker de Joao Pessoa/PB. A experiencia e responsiva, orientada a video e apresenta trabalhos de Reels, comerciais, lifestyle e captacao aerea, com cases detalhados, filtros por categoria e dominio proprio.

**Tecnologias:** React, JavaScript, Vite, Cloudflare, DNS e dominio proprio.

[Acessar projeto](https://edvaldofilms.com.br/)

### Portfy

Builder web para criacao de portfolios interativos e personalizaveis. O projeto esta em desenvolvimento e possui fluxo guiado em seis etapas, quatro templates para desenvolvedores, personalizacao visual, secoes reordenaveis e salvamento automatico do rascunho no navegador.

**Tecnologias:** React 19, TypeScript, Vite, IndexedDB, Lucide React, CSS, Oxlint e GitHub Pages.

[Acessar prototipo](https://wendell-ramos.github.io/GeradorPortfolios/)

### Portfolio Peu

Prototipo de portfolio criativo desenvolvido para cliente, como previa navegavel de direcao visual e experiencia interativa para apresentar atuacao em cultura digital, memes, tendencias, comunidades e grandes audiencias.

**Tecnologias:** HTML5, CSS3, JavaScript, Canvas, design responsivo e GitHub Pages.

[Acessar previa](https://wendell-ramos.github.io/PortfolioPeu/)

### FinControl

Sistema web de controle financeiro pessoal com dashboard, receitas, despesas, metas e categorias. O projeto foi migrado para uma arquitetura mais simples e estavel na Cloudflare, com frontend no Pages, backend em Pages Functions, API em `/api` e banco Cloudflare D1.

**Tecnologias:** Cloudflare Pages, Pages Functions, Cloudflare D1, SQL, JavaScript e migrations.

[Acessar projeto](https://fincontrol-2os.pages.dev/)

### Sistema de Pericia Contabil

Sistema web para gestao de atividades de pericia contabil, com autenticacao, permissoes, acompanhamento de tarefas e fluxo de analise. A hospedagem esta em revisao apos o encerramento da assinatura da Azure.

**Tecnologias:** C#, ASP.NET MVC, Entity Framework e PostgreSQL.

## Responsividade

A interface foi adaptada para diferentes dimensoes:

- Em desktops, os atalhos sao distribuidos de acordo com a altura disponivel.
- Em telas menores, os atalhos sao organizados em duas linhas para evitar rolagem horizontal.
- As janelas respeitam a area util acima da barra de tarefas.
- A grade de projetos se adapta para desktop, notebook, tablet e celular.
- A janela de habilidades foi compactada para evitar rolagem em telas maiores.
